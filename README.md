# OpenClaw OS — Landing Site

Static site for OpenClaw OS hosted on GitHub Pages. Contains:

- `index.html` — landing page
- `privacy.html` — privacy policy (GDPR-compliant, Ireland)
- `terms.html` — terms of service
- `data-deletion.html` — data deletion instructions

## Deploying

1. Push this folder to a public GitHub repository named `openclaw-site` (or anything you prefer).
2. In the repo settings → Pages → set **Source** to `main` branch / root.
3. Site goes live at `https://<your-username>.github.io/openclaw-site/`.

## Used for

Meta App Review submission for the OpenClaw OS Instagram integration. The three legal URLs are required fields in the Meta dev dashboard.
